# FRK Productions

FRK Productions is a Pan India Creative Collective. We are building the creative operating system for India, connecting filmmakers, actors, photographers, designers, writers, musicians, and storytellers. 

## Features

* Member Directory
* Collab Board
* Creative Challenges
* Regional City Chapters

## Tech Stack

* Next.js 14
* React 18
* Tailwind CSS
* Framer Motion

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open http://localhost:3000 with your browser to see the result.

## Join the Community

You can join the WhatsApp community directly from our website and begin collaborating with other creators across India.
